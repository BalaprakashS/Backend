REACT BASICS – 5 READING / THEORY TASKS

TASK 1 – REACT BASICS

1. What is React?

React is a JavaScript library used to build user interfaces, especially for web applications.

2. Why do we use React?

We use React to:

  • Build interactive websites.
  • Create reusable UI components.
  • Manage changing data easily.
  • Build Single Page Applications.
  • Make UI development organized.

3. Is React a library or framework?

React is a JavaScript library, mainly focused on building user interfaces.

4. What are the main features of React?

  • Components
  • JSX
  • Props
  • State
  • Declarative UI
  • Virtual DOM
  • Reusability
  • One-way data flow

5. What is a Single Page Application (SPA)?

A Single Page Application is a web application where the browser loads one main page and updates the required content without completely reloading the page.

6. What is declarative UI?

Declarative UI means describing what the UI should look like. React handles the process of updating the UI.

TASK 2 – COMPONENTS

1. What is a Component in React?

A component is a reusable piece of UI in a React application. 

function Welcome() {
    return <h1>Hello</h1>;
}

2. Why do we use Components?

  • To reuse code.
  • To organize the application.
  • To make code easier to maintain.
  • To divide a large UI into smaller parts.

3. What is a Functional Component?

A functional component is a JavaScript function that returns JSX. 

function App() {
    return <h1>Hello React</h1>;
}

4. What is Component-Based Architecture?

It is an approach where an application is divided into small, independent and reusable components. 

App
 ├── Navbar
 ├── Home
 ├── Product
 └── Footer

5. What is a Component Tree?

A component tree shows the parent-child relationship between components. 

App
 ├── Navbar
 ├── Main
 │    ├── Card
 │    └── Card
 └── Footer

6. Why should component names start with a capital letter?

React uses capitalization to distinguish custom components from HTML elements. 

function Header() {
    return <h1>Header</h1>;
}

<Header />

7. What is a reusable component?

A reusable component is a component that can be used multiple times in different places. 

function Button() {
    return <button>Click</button>;
}

<Button />
<Button />
<Button />

TASK 3 – JSX

1. What is JSX?

JSX stands for JavaScript XML. It allows us to write HTML-like syntax inside JavaScript code. 

const element = <h1>Hello React</h1>;

2. Why do we use JSX in React?

  • It is easy to read.
  • It is easy to write.
  • It makes UI code easier to understand.
  • It combines JavaScript logic with UI.

3. Is JSX HTML?

No. JSX looks similar to HTML, but it is JavaScript syntax that is transformed into React elements.

4. How do we write JavaScript expressions inside JSX?

We use curly braces {}. 

const name = "Bala";

return <h1>Hello {name}</h1>;

5. Why do we use className instead of class?

React uses className instead of class for CSS classes. 

<div className="container">
    Hello
</div>

6. What is React Fragment?

A Fragment allows us to group multiple elements without adding an extra HTML element to the DOM. 

<>
    <h1>Hello</h1>
    <p>Welcome</p>
</>

7. What are the important JSX rules?

  • Return one parent element or Fragment.
  • Close all HTML tags.
  • Use className instead of class.
  • Use {} for JavaScript expressions.
  • Use camelCase for many JSX attributes.
<button onClick={handleClick}>Click</button>

TASK 4 – DOM, VIRTUAL DOM & RECONCILIATION

1. What is DOM?

DOM stands for Document Object Model. It represents the HTML page as a tree of objects that JavaScript can access and modify. 

HTML
 ├── head
 └── body
      ├── h1
      └── p

2. What is Virtual DOM?

Virtual DOM is an in-memory representation of the UI that React uses to determine what parts of the UI need to be updated.

3. What is the difference between DOM and Virtual DOM?

DOM Virtual DOM
Represents the actual browser UI. Represents the UI in memory.
Managed by the browser. Used by React.
Changes affect the actual page. Helps calculate required changes.
Can be expensive to update frequently. Helps minimize unnecessary DOM updates.

4. What is Reconciliation in React?

Reconciliation is React's process of comparing the previous rendered result with the new rendered result and determining what needs to change in the actual DOM.

5. What is Diffing?

Diffing is the comparison process React uses to identify differences between the previous and new element trees. 

Previous:
<h1>Hello</h1>

New:
<h1>Welcome</h1>

React detects that the text has changed.

6. How does React identify changes in the UI?

React compares the previous and new React element trees during reconciliation. It uses element types, position and keys for list items to determine which elements changed.

7. Why is key important while rendering lists?

A key gives each list item a stable identity. It helps React correctly identify items when a list is added to, removed from, or reordered. 

users.map(user => (
    <p key={user.id}>{user.name}</p>
))

1. What is Rendering?

Rendering is the process where React runs a component and calculates what the UI should look like. 

function App() {
    return <h1>Hello</h1>;
}

2. What is Re-rendering?

Re-rendering means React runs a component again to calculate its updated UI. It can happen when state or props change.

3. What causes a component to re-render?

  • State changes.
  • Parent component re-renders.
  • Context value changes.
  • Other React updates can cause rendering.
const [count, setCount] = useState(0);

setCount(count + 1);

4. Does re-render mean the complete browser DOM is recreated?

No. A re-render does not mean React destroys and recreates the entire browser DOM.

React calculates the new UI representation, compares it with the previous one, and applies the necessary DOM changes.

5. What happens during reconciliation?

  1. React gets the new rendered result.
  2. React compares it with the previous result.
  3. React identifies differences.
  4. React determines the required DOM changes.
  5. React commits those changes to the browser DOM.

6. What is the relationship between Virtual DOM, Diffing and Reconciliation?

New UI
  ↓
React Element Tree
  ↓
Reconciliation
  ↓
Diffing / Comparison
  ↓
Find Required Changes
  ↓
Update Actual DOM

Virtual DOM: An in-memory representation of the UI.

Diffing: Comparing the previous and new UI representations.

Reconciliation: The broader process React uses to determine how the UI should be updated.

7. Explain the React rendering process in your own words.

First, React runs the component and creates a representation of the UI from JSX. When state or props change, React renders the component again. React then compares the new result with the previous result. This comparison is part of reconciliation and uses diffing to find what changed. Finally, React updates only the necessary parts of the browser DOM, and the user sees the updated UI.
